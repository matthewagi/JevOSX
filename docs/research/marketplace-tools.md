# Tools on Facebook Marketplace: a small price survey

29 September 2026, 16:07–16:21. Facebook Marketplace, location Attard, within 17 km (in practice all of Malta). JevOSX
did the navigation for each search: it opened Marketplace, typed into "Search Marketplace" and pressed Return. The
results page was then read with `jevosx observe`. Only the first screen of results was read (12 cards per search,
no scrolling). Nothing was opened, saved, liked or messaged. Seller names and profiles were not recorded.

**How to read the numbers.** The price statistics leave out cards priced €0 or €1, which sellers use for "ask me".
They also leave out items that are not the tool searched for (Facebook's matching is loose). The cards do not show
condition, so condition is only known when the title says so. Getting it for the rest would mean opening each
listing.

## Across the five searches

- Hand-held tools (drills, grinders, socket sets) mostly sit at €20–€90, with medians around €50. The bigger
  machines have medians of €120 (welders, dragged down by cheap stick sets) and €220 (mitre saws).
- About one card in six was priced €0 or €1, meaning "ask". Real prices for those need a message, which this
  survey did not send.
- Several listings look like small shops or traders: Efftool in Żebbuġ, the "88VFmax" kits in Ħamrun, and
  Marsaskala for welding. Private sellers are the rest.
- Condition is the biggest gap. The results cards do not show it, and only 6 or 7 of the 60 titles say "new". A follow-up could
  have JevOSX open the top candidates, read-only, and note the condition field.

Four bugs were found and fixed, each with a test:

1. **One-tap sign-in.** Facebook showed a login wall. Jev clicked "Allow all cookies" and then the account picker
   "Continue <name>" four times. It only reached the password page, and no password was typed, but an account
   picker can sign in without a password. It is now a careful step that always asks the person, unless the goal
   asks to sign in.
2. **Chrome's inline completion.** Typing "facebook.com" and pressing Return opened
   `facebook.com/marketplace/create/item`, which Chrome had completed from earlier runs. Forward Delete now removes
   a selected completion before Return.
3. **Clicking a link did not wait for the page.** After "Marketplace", Jev typed into the old page's "Search
   Facebook" box and searched all of Facebook. Link clicks now wait for a new title; the address alone changes
   0.6 s too early on Facebook.
4. **A page with a title but no content counted as loaded.** Jev saw an empty page and typed the address again.
   A page now has to have something readable in it.

With all four fixes in, the last two searches took the shortest path: 4 steps in 17–20 s.

Still open:

- Jev sometimes reuses an existing Facebook window rather than the fresh one. That is harmless here, but it means
  the results can end up in a background window.
- The first TYPE_TEXT into Facebook's "Search Marketplace" once reported "typed text did not appear", although
  the text was there.
- The reader's plan for the first search was wrong ("buy it now · send message · send"). Nothing acted on it.
